# Code Examples & Recipes

Integration code examples bound to live Public API `operationId` definitions.

## Featured Recipes

1. **Campaign Creation**: List and inspect campaigns via `/api/v1/campaigns`
2. **Assignment Claim**: Claim work items via `/api/v1/assignments/{id}/claim`
3. **Trust Passport**: Read worker passports via `/api/v1/trust/{id}/passport`
4. **Analytics Snapshots**: Fetch performance rollups via `/api/v1/analytics/snapshots`
5. **Forecast Retrieval**: Fetch advisory predictions via `/api/v1/forecasts/campaign`
6. **Report Generation**: Schedule and generate reports via `/api/v1/reports/generate`
7. **Automation Rules**: Draft governed rules via `/api/v1/automation/rules/draft`
8. **Webhooks Setup**: Register subscriptions via `/api/v1/webhooks`
