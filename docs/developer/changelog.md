# API Changelog & Release Notes

Track version changes and new additions to the ZOLANZO Public API platform.

## Current Release: v1.0.0 (2026-07-26)

- **Public API v1 Gateway**: Sole external entry point under `/api/v1/`
- **Webhooks v1**: Managed outbound event platform with HMAC signatures
- **Integration Marketplace**: 7 starter connectors operating strictly on Public API v1
- **Developer Portal**: SDK Generator, API Explorer, and interactive documentation
