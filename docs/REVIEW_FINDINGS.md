# Review Findings

Structured findings — not free-text only.

| Field | Purpose |
| --- | --- |
| `category` | missing_evidence, gps_mismatch, blurry_image, rule_violation, wrong_language, incomplete_checklist, quality, other |
| `severity` | info · warning · major · critical |
| `assignmentStepKey` | Optional step link |
| `evidenceItemId` | Optional evidence link |
| `validatorResultId` | Optional validator result link |
| `message` | What was observed |
| `recommendation` | What should change |

Reusable for analytics, reviewer training, and future AI assistance.
