# Audit Explorer

Search operational and platform audit trails.

## Filters

- Public IDs
- Users
- Organizations
- Campaigns / Assignments / Submissions
- Ledger transaction ids
- Date range
- Operation type (action contains)

## Sources

1. `OperationalAudit` — ops commands and queue actions
2. `AuditLog` — platform audit log

API: `searchAuditExplorer` / `searchAuditExplorerAction`.
