# Submission Summary

Generated automatically at submit time.

Includes:

- `timeSpentSeconds` (assignment startedAt → submittedAt)
- Step completion counts (completed / required / requiredCompleted)
- `evidenceCounts` by kind
- `executionMetrics` (progress %, item count, context keys)
- `workerNotesSummary` (private notes concatenated)

Stored in `submission_summaries`, linked 1:1 to the Submission Package.
